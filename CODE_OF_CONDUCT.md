# Community conduct

Vault Gallery’s project spaces are for careful technical collaboration. Be respectful, specific and
patient. Critique behavior, code and decisions rather than people. Do not harass, threaten, demean,
discriminate against or expose another person’s private information.

Because this is a gallery and privacy project, never post unredacted private media, contact names,
locations, encryption material, PINs, biometric data, device identifiers or private logs. Use
synthetic reproduction files.

Maintainers may edit or remove content, close discussions and restrict participation when necessary
to protect users and keep collaboration productive. Serious security concerns should be reported
privately through the process in [`SECURITY.md`](SECURITY.md).
