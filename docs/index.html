One gallery model

Public and private, without learning two apps.

  • MediaStore-backed library
  • Android-approved mutations
  • Albums, timeline, stories and search
  • Full viewer, editor and create surfaces

Secure Gallery

  • PIN and biometric authentication
  • Encrypted or locked-only storage
  • Matching album, viewer and editor concepts
  • Controlled external-app access
  • Persistent payload and recovery boundaries
Move means move

A transfer has an invariant, not a hopeful animation.

The source survives until the destination is written, flushed, verified and committed. Long operations continue in the background and remain controllable.

1. StageWrite a temporary destination with source context.
2. VerifyFlush bytes and validate the destination.
3. CommitWrite metadata and make the item visible.
4. ApproveRequest Android mutation approval when required.
5. FinishDelete the source only for a verified move.
Under the product

Explore the architecture.

The app is split by durable product responsibility, with one Android shell wiring public and secure experiences to shared domains.

Feature-oriented Gradle modules

The application shell integrates design-system, database, security, gallery, viewer, editor, creation, transfer, search and AI boundaries. Mature implementations still being extracted remain in the app module to preserve tested behavior.

Application-level protection

Keystore wrapping, Argon2-derived credentials, authenticated encryption, bounded URI grants and lifecycle locking protect the vault within the documented threat model. Vault Gallery does not claim to be an operating-system secure container.

Replaceable local runtimes

Selection, OCR, similarity and inpainting sit behind explicit local backends. Model identity and checksums are versioned. Neural output is separated from deterministic processing and never described as a cloud feature when it is not one.

Platform contracts first

MediaStore owns public media identity, system prompts own dangerous mutations and biometrics, WorkManager owns durable operations, and intent filters expose only supported viewer/editor/review/picker capabilities.

Build and verify

One command for the local gate.

Clone with Git LFS, use JDK 17 and Android SDK 35, then run the same unit-test, lint and assembly gate recorded for Version 1.

git lfs install
git clone https://github.com/danyalwg/VaultGallery.git
cd VaultGallery
git lfs pull
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
Signing boundary: the GitHub APK is a debug-signed evaluation artifact. Production release signing credentials are deliberately not stored in this repository.
